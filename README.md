# Horizon Config 2.0 — Beta 1

**Evolved from HEAVYPOLY Config.**

Horizon Config continues the fast, direct Blender workflow established by HEAVYPOLY, updated, Evolved for Blender 5.2 LTS and maintained by Hao / Horizon Workshop.

INSTALLATION

1. Download the ZIP.
2. Open ZIP, Move the included `portable` folder beside `blender.exe` inside 5,2,1 LTS portable folder.
3. Start Blender 5.2.1 LTS.

See the included README for Windows and macOS installation instructions.

New feature include - ONE KEY (N side menu) toggle from HP keymapping to Vanilla keymapping, Eevee Bloomm. 

## Compatibility

- Blender 5.2.1 LTS
- Windows portable installation
- macOS portable or user installation
